## R2 - Three engines and my choice
1. GODOT / supports both 2d AND 3d games / the two main languages supported are C# and GDScript / a useful feature is that it uses nodes so it is more organized and easier to navigate, and if you create a character or scene, you can reuse the exact scene anywhere else in the project / https://godotengine.org/
2. UNITY / supports both 2d AND 3d games, however, 3d is used more / C# is the main language / it is easy to create props and maintain lighting / https://unity.com/
3. STRIDE / supports both 3d AND 3d games, focused more on 3d VR games / C# / it has VR support and is more open source / https://www.stride3d.net/
I would use Godot because out of the options listed, it seemed most beginner friendly to me. The UI is similar to Visual Studio, and because I've used it before, I would find it easiest to navigate through.
